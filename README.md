# The Birthday Bakehouse

A responsive, interactive baking-themed birthday experience made for Boipelo.

## Features
- Interactive ingredient-adding and mixing sequence
- Oven baking moment with a timed reveal
- Custom cake decorating: frosting colors, toppings, candles
- Birthday cake reveal with confetti
- Personal note from Ntsako
- Optional tiny synthesized sound chord
- Mobile-friendly layout and reduced-motion support

## Run locally
Open `index.html` in a browser. No build tools or dependencies required.

## GitHub Pages
Configured to publish from the `main` branch, root folder.
